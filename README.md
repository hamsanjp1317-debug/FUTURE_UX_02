FitZone Fitness App UI/UX Design
This project was created as part of the UI/UX Design Internship at Future Interns.
Project Overview
FitZone is a mobile fitness training application designed to help users easily book workout sessions and fitness programs.
Included Screens
- Welcome/Login Screen
- Program Selection Screen
- Booking Screen
- Confirmation Screen
Features
- Easy appointment booking
- Fitness program selection
-Mobile-friendly UI
- Simple user flow
